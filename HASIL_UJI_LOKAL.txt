## dhcp

```text

====================================================================
Sistem Pakar Identifikasi Gangguan Koneksi Wi-Fi pada Windows
Pengujian: Kasus 1 - Indikasi masalah DHCP
====================================================================
Gejala yang dimasukkan:
  - Alamat IPv4 perangkat adalah 169.254.x.x
  - Perangkat tidak dapat mengakses internet
  - Perangkat terhubung ke jaringan Wi-Fi

Proses penelusuran aturan (Forward Chaining):
  Langkah 1: R2 menghasilkan Wi-Fi terhubung, tetapi internet tidak dapat diakses
  Langkah 2: R3 menghasilkan Windows diduga tidak memperoleh alamat IP dari router melalui DHCP
  Langkah 3: R4 menghasilkan Kemungkinan ada masalah pada pemberian alamat IP (DHCP)

Hasil identifikasi:

KESIMPULAN: Kemungkinan ada masalah pada pemberian alamat IP (DHCP)
Dasar kesimpulan:
  - Kemungkinan ada masalah pada pemberian alamat IP (DHCP) <- R4 [S1: Microsoft Support]
      - Wi-Fi terhubung, tetapi internet tidak dapat diakses <- R2 [S1: Microsoft Support]
          - Gejala yang dimasukkan: Perangkat terhubung ke jaringan Wi-Fi
          - Gejala yang dimasukkan: Perangkat tidak dapat mengakses internet
      - Windows diduga tidak memperoleh alamat IP dari router melalui DHCP <- R3 [S1: Microsoft Support]
          - Gejala yang dimasukkan: Alamat IPv4 perangkat adalah 169.254.x.x

Batas penggunaan sistem:
Basis pengetahuan ini dibuat untuk membantu pemeriksaan awal beberapa masalah koneksi Wi-Fi pada perangkat Windows. Aturan disusun dari panduan Microsoft Support dan dokumentasi Cisco. Pemeriksaan dibatasi pada alamat IP/DHCP, server DNS, kualitas sinyal, penggunaan bandwidth oleh aplikasi latar belakang, dan interferensi Wi-Fi. Program tidak membaca kondisi jaringan secara langsung; hasil bergantung pada jawaban pengguna dan skenario yang dimasukkan. Karena itu, hasil hanya berupa indikasi awal dan bukan diagnosis pasti.
====================================================================
```
